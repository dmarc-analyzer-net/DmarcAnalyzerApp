{{ if eq (include "dmarc.migrationStrategy" .) "startup" -}}
The app applies migrations as it boots, so the first pod can take a few minutes
to become ready on a large database. That is the migration running, not a hang:

  kubectl -n {{ .Release.Namespace }} logs -f deploy/{{ include "dmarc.fullname" . }}
{{- else -}}
Migrations ran in a Job before this release started:

  kubectl -n {{ .Release.Namespace }} logs job/{{ include "dmarc.fullname" . }}-migrate-{{ .Release.Revision }}
{{- end }}

{{ if and .Values.postgres.enabled (not .Values.auth.existingSecret) -}}
Two things to change before this is anything but a trial:

  * The bundled PostgreSQL has no replication and no backups. Set
    postgres.enabled=false and point externalDatabase at a managed instance.
  * The encryption key is in your values file. Move it to a Secret and set
    auth.existingSecret. Losing or changing that key makes every stored mailbox
    credential undecryptable.
{{- end }}
